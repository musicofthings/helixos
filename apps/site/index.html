One workspace for wet-lab truth.

HelixOS keeps ELN structure, reusable protocols, sequence tooling, and MCP connectors under a single Slack-style shell — in the browser for development, or as a local desktop app with an API sidecar.

Workspaces as channels

Switch labs like channels. Each workspace has a home, projects, and a scoped lab notebook.

Protocols library

Create, edit, and import protocol shells. Wire live protocols.io fetch as the next step.

Desktop-local by design

Electron packs the UI with a FastAPI sidecar and MCP bridge so connectors stay on your machine.

Audit-ready trail

Hash-chained audit events for regulated actions — built as a first-class domain, not an afterthought.

Get started

Prefer a packaged app? Grab the latest macOS build. Prefer hacking on the monorepo? Run the browser stack in two commands.

Download

macOS DMG from GitHub Releases. Builds are not Apple-notarized yet — open via System Settings if Gatekeeper warns.
